# Raster Data

![Rasters!](https://live.staticflickr.com/65535/50510757837_c3606682ac_c_d.jpg)

## Impetus

For continuously distributed data, the raster data structure is a much more efficient approach.

## Module Learning Objectives

### Understand and Manipulate Raster Data Structures

> Learners will describe the raster data structure used for continuously distributed spatial data, and manipulate and transform raster objects in R.

- **Bloom's Levels:** Understand, Apply
- **Reinforces:** Contrasts with the vector (point/line/polygon) data covered in Spatial Points and Shapefiles, completing the two core spatial data models used in the course.
- **Notes:** Framed around efficiency — rasters are introduced as the appropriate structure specifically for continuous, not discrete, spatial data.

### Visualize and Extract Information from Raster Data

> Learners will visualize raster data using both base R and `ggplot()` approaches, and extract raster values at specific locations using point data.

- **Bloom's Levels:** Apply
- **Reinforces:** Connects back to point data handling from Spatial Points, using the beetle data set as a shared example across both modules.
- **Notes:** Extraction (raster-to-point) is the practical skill most directly reused in later applied analyses.
